# SFH flow authoring

Use `sfh-flow-design` for a new execution graph, or `sfh-flow-review` to audit an existing flow. Consult a specialist only for the relevant issue: loops, route evidence, workspace/context, recovery, CI, external tools or regression evals. References are optional detail, not a mandatory reading sequence.

Use the installed SFH guide/schema; do not invent YAML fields. Validate and dry-run authored flows. Before live execution, inspect preflight/plan results and unresolved effects. SFH follows declared routes; checks or evaluators supply quality judgments.
